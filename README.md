# 汕尾打黑钓点助手

一个手机浏览器打开就能用的网页应用：自动定位 → 分析附近淡水水域 → 按黑鱼（乌鳢）习性打分推荐 → 地图标点 → 一键唤起高德导航 → 记录实战结果越用越准。

## 文件结构

```
shanwei-fishing/
├── index.html      # 主页面
├── style.css       # 样式（暗色手机风格）
├── app.js          # 核心逻辑（打分引擎 + 地图 + 交互）
└── data/
    └── water.js    # 汕尾市 1898 个真实水体数据（OSM 开源数据）
```

## 使用前唯一要做的事：申请高德地图 Key

1. 打开 https://lbs.amap.com/ 注册/登录（手机号即可）
2. 顶部「控制台」→「应用管理」→「我的应用」→「创建新应用」
3. 应用类型选 **「Web端(JS API)」**，获取一个 **Key**
4. （新版可能还需要一个「安全密钥 securityJsCode」，同样在应用详情里能看到）
5. 打开 `app.js`，找到最上面的 `CONFIG`：
   - 把 `amapKey: 'YOUR_AMAP_KEY'` 改成你的 Key
   - 如果有安全密钥，把 `amapSecurityCode: ''` 也填上
6. 保存即可

> 注意：Key 需要绑定域名白名单。本地测试可以用 `localhost`，正式部署后要改成你的域名。

## 本地预览

因为要用到定位和地图，建议用本地服务器打开（直接双击 HTML 也行，但定位权限更稳）：

```bash
cd shanwei-fishing
python3 -m http.server 8080
```

然后手机和电脑连同一 WiFi，手机浏览器访问 `http://电脑IP:8080`。

## 手机当 App 用（推荐）

打开网页后，用手机浏览器菜单 →「添加到主屏幕」，图标会出现在桌面，点开全屏无地址栏，体验接近原生 App。

## 核心思路（老师傅经验数字化）

黑鱼（乌鳢）的习性决定了它爱待的地方：

| 习性 | 对应的水域特征 | 打分权重 |
|---|---|---|
| 喜静水、水草芦苇 | 水塘/野塘/沟渠 > 溪流 > 大江大河 | 类型基础分 |
| 爱小型水体、好找鱼 | 小 > 中 > 大 | 大小分级 |
| 春季产卵靠岸 | 春：池塘沟渠 +8 分 | 季节调整 |
| 秋季进食旺季 | 秋：全体 +3 分 | 季节调整 |
| 冬季蛰伏深水 | 冬：全体 -12，大水 +6 | 季节调整 |
| 讲究就近 | 距离越近分越高 | 距离加权 |
| 无名野塘少人钓 | 无名 +4 分 | 命名微调 |

最终每个水体得到一个 0–100 的「推荐度」，排序后标在地图上。

## 数据说明

- 水体数据来自 OpenStreetMap 开源数据（ODbL 协议），覆盖汕尾市 1898 个水体：水塘 986、河流 296、溪流 276、沟渠 190、蓄水区 150。
- 只覆盖地图数据里有的水体；特别小的野塘、新挖的塘可能不在数据里，需要你手动补充（后续版本加「手动标点」）。
